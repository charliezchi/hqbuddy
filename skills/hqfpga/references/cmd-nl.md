# nl.* 网表处理命令

以下命令均用于网表（netlist）层面的处理。命令名的 `[<nview>]` 参数均指某个模块所对应的网表视图（netlist view）；省略时默认作用于顶层设计网表。

## nl.clean

清除网表无用的元件实例（instance）和连线（net），例如"孤儿"元件实例或没有驱动的连线。

### 语法

```txt
nl.clean [<nview>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| nview | 对象引用 | 无 | 指定要清除的模块（所对应的网表视图）。未指定时清除顶层设计网表中的无用元件实例和连线。 |

### 示例

```txt
nl.clean
```

清除顶层设计网表中的无用元件实例和连线。

## nl.flatten

本命令用于"展平"（flatten）层次化设计网表。

### 语法

```txt
nl.flatten [<nview>] -nmnc
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| nview | 对象引用 | 无 | 指定要展平的模块（所对应的网表视图）。未指定时展平顶层设计网表。 |
| nmnc | 开关 | 无 | `-nmnc` = no more netlist change，表示展平网表之后网表将不再变化，从而使得展平操作可以做一些特殊处理。 |

### 说明

- 对层次化网表执行后，网表只保留一个层次。
- 若在操作前某些模块被设置成"层次保留"（通过命令 `impl.guide.set -keep_hier`），本操作将对相应模块的层次结构进行"软"展平（soft flattening）。被软展平的模块将来可通过 `nl.unflatten` 命令恢复实际的模块层次。
- 【注】本命令必须与 `nl.unflatten` 成对使用 —— 无论网表中是否有需要保留层次的模块。
- 逻辑优化、工艺映射、组装、布局、布线等核心优化例程都需要在展平的网表上工作，因此在运行这些例程之前需调用 `nl.flatten`，例程运行结束后调用 `nl.unflatten` 恢复被"软展平"的模块层次。例如 `design.place` 就封装了如下命令序列：

```txt
nl.flatten -nmnc
impl.place
nl.unflatten
```

（其中 `impl.place` 是进行布局操作的核心例程）

- 【注】软展平会使层次边界处连线的扇出计算变得不准确；如果确定展平后网表不会发生变化，可加 `-nmnc` 选项使本操作进行特殊处理来解决扇出计算问题，所以通常在布局、布线之前运行本命令都要加 `-nmnc` 选项。

### 示例

```txt
nl.flatten
```

展平当前设计网表。

```txt
nl.flatten /work/core1
```

展平 work 库中名为 core1 的模块。

## nl.ioinsertion

本命令用于插入 IO 单元。

### 语法

```txt
nl.ioinsertion
```

### 参数

无。

### 说明

本命令为每个 IO 端口（port）插入相应的 IO 单元；如果端口已经与 IO 单元相连，本操作不会重复插入 IO 单元。通常用于工艺无关的网表，例如 RTL 综合之后形成的与工艺无关的网表，或读入 MCNC EDIF 文件后形成的网表。

## nl.primbind

本命令用于将逻辑综合、映射产生的基本逻辑元件（primitives）绑定到目标 synlib 库上。例如逻辑综合产生了一个 3 输入的与门，通过本命令可以将其绑定到目标库的 LUT3 单元上。

### 语法

```txt
nl.primbind [<comb>] [<seq>] [<io>] [<no_absorb_seq_inv>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| comb | 开关 | 无 | 指定是否绑定组合元件。 |
| seq | 开关 | 无 | 指定是否绑定时序元件。 |
| io | 开关 | 无 | 指定是否绑定输入输出单元。 |
| no_absorb_seq_inv | 开关 | 无 | 仅当已指定参数 `seq` 时有效：指定绑定时序元件时是否尽量尝试将驱动时序元件的反相器作为反向引脚（"bubbled pin"）吸收入时序元件。 |

### 示例

```txt
nl.primbind -comb -seq
```

将网表中的组合及时序逻辑元件绑定到目标库。

## nl.pstru.build

本命令用于建立或更新物理网表。

### 语法

```txt
nl.pstru.build [<nview>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| nview | 网表视图（nview） | 顶层模块的 nview | 指定要建立物理网表的网表视图（模块）。 |

### 说明

当设计实现过程中物理单元的配置信息发生变化时，需调用本命令为物理单元建立或更新物理网表。例如当一个 SLICE 被配置成一个 LUT+DFF 时，调用本命令为该 SLICE 建立物理网表（由 LUT 和 DFF 组成）。

### 示例

```txt
nl.pstru.build
```

对顶层设计网表中的物理单元建立物理网表。

## nl.report

本命令用于报告当前网表的状态。

### 语法

```txt
nl.report [-check] [-file <file_value>] [-location] [-ratio]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| check | 开关 | 无 | 检查是否所有的元件都有确定位置。 |
| file | 字符串 | 无 | 缺省情况下报告输出到标准输出（stdout）；使用本参数可将报告输出到指定文件。 |
| location | 开关 | 无 | 缺省情况下网表报告包括两部分：资源利用率报告和元件位置报告。使用本参数可指定仅输出元件位置报告。 |
| ratio | 开关 | 无 | 缺省情况下网表报告包括两部分：资源利用率报告和元件位置报告。使用本参数可指定仅输出资源利用率报告。 |

### 示例

```txt
nl.report -ratio -file my.rpt
```

输出资源利用率报告到文件"my.rpt"中。

## nl.revext

本命令用于从已实现的设计中反向提取逻辑网表。

### 语法

```txt
nl.revext [<nview>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| nview | 对象引用 | 无 | 指定要进行反向逻辑网表提取的模块（所对应的网表视图）。未指定时对当前设计中所有模块进行反向逻辑网表提取。 |

### 说明

通常用于设计的反复迭代优化流程：当设计经过映射、组装、布局、布线等步骤在目标器件上实现后，可以得到准确时序信息（如单元和互连延迟），此时可通过本命令从已实现好的网表中反向提取出逻辑网表（即工艺映射网表）。该网表与正常流程中的工艺映射网表不同之处在于有准确的时序信息，在此网表基础上重新进行组装、布局、布线操作有望得到进一步优化的结果。

### 示例

```txt
nl.revext
```

对当前设计进行反向逻辑网表提取。

## nl.unflatten

本命令用于恢复被 `nl.flatten` 命令"软展平"的层次结构。

### 语法

```txt
nl.unflatten [<nview>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| nview | 对象引用 | 无 | 指定要 unflatten 的模块（所对应的网表视图）。未指定时对顶层设计网表进行 unflatten 操作。 |

### 说明

- 恢复被 `nl.flatten` 命令"软展平"的层次结构。
- 【注】如果在 `nl.flatten` 中没有被软展平的模块，则本操作完成后将不产生任何层次结构。
- 须与 `nl.flatten` 成对使用（详见 nl.flatten 说明）。

### 示例

```txt
nl.unflatten
```

对顶层设计网表进行 unflatten 操作。

## nl.uniquify

本命令用于对层次化网表进行 uniquify 操作。uniquify 是指当一个用户模块存在多个实例（instance）时，复制该模块使得每个模块只有一个实例。

### 语法

```txt
nl.uniquify [<nview>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| nview | 对象引用 | 无 | 指定要 uniquify 的模块（所对应的网表视图）。未指定时对顶层设计网表进行 uniquify 操作。 |

### 示例

```txt
nl.uniquify
```

对顶层设计网表进行 uniquify 操作。

## nl.write

本命令用于输出 Verilog 格式的网表文件，以及相关的逻辑、延时及物理层次等信息。

### 语法

```txt
nl.write <filename> [-eqn] [-phy] [-sdf] [-loc] [-lib <lib_value>]
```

### 参数

| 参数 | 类型 | 缺省值 | 说明 |
|------|------|--------|------|
| filename | 字符串 | 无 | 指定要输出的 Verilog 网表文件名称。 |
| eqn | 开关 | 无 | 缺省输出结构化网表，即网表中仅包含元件例示（instance）及连线，对组合逻辑元件只输出元件名称和端口连接，而不输出逻辑功能。指定本参数后，对组合逻辑元件将输出其逻辑表达式。 |
| sdf | 开关 | 无 | 指定时输出与 Verilog 文件对应的 SDF 文件，SDF 文件的主名称与 Verilog 文件相同（仅扩展名不同）。【注】本参数与参数 `phy` 或参数 `lib` 互斥。 |
| phy | 开关 | 无 | 指定在 Verilog 网表中输出物理层次（如果存在）信息。物理层次指目标 FPGA 器件上的硬件网表层次，例如对 SEALION 器件，根据配置信息的不同，一个 SLICE 可能由 LUT、FF、CCU、RAM、ROM 等元件组成。未指定时，输出的 Verilog 文件中看不到 SLICE；指定时，SLICE 将作为 Verilog 的模块（module）输出。 |
| loc | 开关 | 无 | 指定在 Verilog 网表中输出元件实例（instance）的物理位置信息（如果存在）。 |
| lib | 字符串 | 无 | 缺省情况下输出顶层设计单元的网表；指定时输出相应名称库（Library）中所有单元的网表。 |

### 说明与注意事项

- `eqn` 的两种输出差异示例：网表中有一个两输入的 AND 门名为 MY_AND2 ——
  - 未指定 `-eqn` 时输出：`MY_AND2 and2_inst (.A(a), .B(b), .O(y));`
  - 指定 `-eqn` 时输出：`assign y = a & b;`
- 【注】`phy` 仅当设计在目标器件上实现之后才起作用，例如在组装（packing）操作完成之后。
- 【注】`phy` 与 `sdf` 互斥。
- `sdf` 与 `phy`、`lib` 互斥。

### 示例

```txt
nl.write mylib.v -lib mylib
```

对库"mylib"中的所有单元，输出它们的网表到文件"mylib.v"中。

```txt
nl.write aft_pl.v -loc -sdf
```

输出名为"aft_pl.v"的 Verilog 文件，同时输出元件实例的位置信息，并输出名为"aft_pl.sdf"的 SDF 文件。

```txt
nl.write mydesign.v -eqn
```

将顶层设计单元的网表输出到文件"mydesign.v"中，组合逻辑将以逻辑表达式的方式输出。
