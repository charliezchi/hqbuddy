# 开发板板卡资料查阅（templates/boards/）

`hqbuddy/templates/boards/` 下每块开发板一个 markdown 文件，是**给 agent 读的板卡手册摘要**——从官方《开发板用户指南》PDF 提炼的全部 FPGA 引脚分配。做引脚约束（.upc / phycst.*）、例程对接、板级调试时按本文件方法查阅。

## 板卡清单

| 文件 | 板卡 | DG 编号 | 器件 |
|---|---|---|---|
| `SA5Z-30-D1.md` | SA5Z-30-D1 | DG05101 | SA5Z-30-D1-8U213C |
| `SA5Z-50.md` | SA5Z-50 | DG05201 | SA5Z-50-D0-7F484C |
| `SA5T-100.md` | SA5T-100 | DG05301 | SA5T_100_D0_8F676C |
| `SA5T-200.md` | SA5T-200 | DG05401 | SA5T-200-D0-7H676CES |

## 文件结构（每块板相同）

1. **H1**：板卡名 + DG/工程编号
2. **头部 bullet**：器件型号与规模、板载 Flash/DDR/MCU、供电与电源树、bank 电压（含跳线/CFGBVS 特殊说明）、注意事项；末行是全局默认值：`未特殊标注时：io_std = LVCMOS33，active 无效`
3. **每外设一个 `##` 小节**：小节标题括号内写默认值（方向、有效电平、bank），表格只列差异项。基础列 `| net | pin |`，有差异时加 direction / active / 说明列
4. **差分对速查**（如有）：LVDS 差分对与引脚映射

## 典型用法

- **查某信号的引脚**：在目标板文件内直接 grep net 名，如 `grep "FPGA_LED1" templates/boards/SA5Z-30-D1.md`
- **写引脚约束**：从表内取 net→pin，io_std 用头部默认值（LVCMOS33）或小节标注值；差分对查"差分对速查"
- **对接例程/排针**：40P 座、FMC、GPIO 等扩展口在小节标题注明了电平与差分能力
- **方向语义**：一律为 **FPGA 视角**（output = FPGA 驱动外设）

## 可信度标注约定

- 引脚分配均与官方 PDF 逐表核对；原文档疑似笔误处**照录并在行内注明**（如"原文如此"）
- 文档未给出的信息（bank 归属、默认跳线档位、某些方向）留空或注明"需查 pinout 文件确认"，**不要臆测填充**
- 使用前若板卡版本与文件头所载版本号不符，需重新核对

## 新增板卡

照现有任一文件的结构新建 `templates/boards/<板名>.md`：头部要点 + 每外设一节 + 默认值写标题、差异写表内；并在本文件的板卡清单表加一行。原始 PDF 引脚表逐行录入，宁多勿漏。
