# SA5Z-50 FPGA 开发板（DG05201，IST071_SA5Z-50-D0-7F484C_EVB_V3_1）

- 器件：SA5Z-50-D0-7F484C，Seal（海豹）5000 系列，28nm，约 54K LUT（54272），STAR（Cortex-M33）硬核最高 250MHz（FPU/DSP/MPU，256KB 指令 SRAM + 192KB 数据 SRAM），DDR2/DDR3 控制器，200 个 DSP18x18，6 PLL/24 DLL，最大用户 I/O 249
- 板载 QSPI NOR Flash：ESMT EN25QX128A-104HIP（丝印 cFeon QX128A），128Mbit，PCB 背面；配置模式默认 M[2:0]=001（Master SPI）；JTAG 为 10Pin 2.54mm 简易牛角座
- 板载 DDR3：ESMT M15T4G16256A(2S)，4Gbit，最高 933MHz；EEPROM：BL24C256（256Kbit I2C，最高 1MHz）
- 供电：12V DC（讯普 DC-091-A200，内径 2mm/外径 6.45mm），板载 5V/3.3V/2.5V/2V/1.8V/1.5V/1.25V/1.0V（ADP5054 + MPM3630GQV + 多路 LDO）
- Bank 电压：VCCIO1、VCCIOJ、VCCIO14 可经跳线选择 3.3V/1.8V/2.5V；CFGBVS 接 VccioJ 时 BankJ/Bank3 为高压模式（3.3V/2.5V），接地时为低压模式（1.8V）。文档未说明各外设引脚具体所在 bank 及实际跳线位置
- 文档未给出各引脚的 bank 归属（个别信号名中含 bank 信息，如 _B1/_B2A/_B3/_B14）
- 未特殊标注时：io_std = LVCMOS33，active 无效
